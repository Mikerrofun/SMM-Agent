бо# Vision — SMM Agent

## Описание

SMM Agent — персональный AI-ассистент для создания контент-плана и подготовки
публикаций в Telegram-канале Натальи.

Основная задача системы — сократить время на поиск тем для новых публикаций,
анализируя контент конкурентов и предлагая релевантные идеи, соответствующие
стилю автора, интересам целевой аудитории и методологии компании.

Система не заменяет автора, а выступает интеллектуальным помощником. Финальное
решение о выборе идеи и публикации всегда принимает человек.

## Цель проекта

Создать сервис, который автоматически:

- анализирует новые публикации конкурентов;
- выявляет потенциально интересные темы;
- предлагает несколько идей для будущих постов;
- помогает быстро создавать полноценные публикации в стиле Натальи;
- снижает время на подготовку контента.

## Основной флоу (MVP)

```
Парсинг каналов конкурентов
        ↓
Анализ новых публикаций
        ↓
Формирование идей (заголовок, тезис, цель)
        ↓
Отправка идей в Telegram-бота
        ↓
Пользователь выбирает идею
        ↓
Генерация полноценного поста в стиле Натальи
        ↓
Ручная редактура и публикация человеком
```

По расписанию (вторник и четверг в 10:00) система анализирует новые публикации
конкурентов и формирует список идей.

Каждая идея содержит:

- цепляющий заголовок;
- основной тезис;
- цель публикации.

## Принципы генерации контента

При генерации контента система должна:

- соблюдать авторский стиль;
- учитывать методологию компании;
- учитывать особенности целевой аудитории;
- писать естественным человеческим языком;
- не использовать шаблонные AI-формулировки;
- предлагать идеи, основанные на анализе новых публикаций конкурентов,
  а не случайных темах;
- не противоречить уже опубликованным материалам;
- минимизировать повторение уже раскрытых тем.

## Цели первого релиза

- Первая версия ориентирована на одного автора — Наталью.
- Система не публикует посты автоматически.
- Каждый этап требует подтверждения пользователем:
  - выбор идеи;
  - генерация поста;
  - ручная редактура перед публикацией.

## Долгосрочное развитие

- несколько вариантов генерации поста по одной идее;
- поиск похожих ранее опубликованных материалов;
- предотвращение повторения тем;
- аналитика конкурентов;
- рекомендации по контент-плану;
- хранение истории генераций;
- поддержка нескольких авторов и проектов.
