# Telegram Bot — Руководство по запуску

## Описание

Telegram Bot является интерфейсом взаимодействия пользователя с SMM Agent. Через бота пользователь получает идеи для постов, выбирает понравившиеся и генерирует готовые публикации.

## Доступные команды

После запуска бота отправь ему в Telegram:

- `/start` — приветствие и описание возможностей
- `/help` — список доступных команд
- `/ideas` — получить новые идеи для постов (пока заглушка)
- `/status` — проверить статус бота

## Проверка работы

1. Запусти бота:
   ```bash
   npm run bot
   ```

2. Открой бота в Telegram (по username, который задал в BotFather)

3. Отправь команду `/start`

4. Бот должен ответить приветственным сообщением

## Структура кода

```
src/bot/
├── index.ts    — основной файл бота (экспорт bot, startBot, stopBot)
├── run.ts      — standalone запуск бота
```

### index.ts

- Инициализация бота
- Регистрация команд
- Обработка ошибок
- Экспорт функций для внешнего использования

### run.ts

- Загрузка переменных окружения
- Запуск бота в режиме long polling
- Graceful shutdown при SIGINT/SIGTERM

## Архитектурные принципы

Согласно архитектуре проекта, bot:

- **Не содержит бизнес-логики**
- Только принимает команды и отправляет сообщения
- Вся логика находится в `services`
- Взаимодействие с БД только через `repositories`

## Следующие шаги

После базовой настройки бота нужно:

1. Подключить services для генерации идей
2. Добавить обработку выбора идей
3. Реализовать генерацию постов
4. Настроить cron для автоматической генерации идей

## Troubleshooting

### Ошибка: "TELEGRAM_BOT_TOKEN is not configured"

Проверь, что:
- Файл `.env.local` существует
- Токен правильно прописан
- Нет лишних пробелов в значении токена

### Бот не отвечает на команды

1. Убедись, что бот запущен (`npm run bot`)
2. Проверь токен бота
3. Убедись, что написал боту напрямую (не в группе)
4. Проверь логи в консоли

### Токен не работает

1. Проверь токен в BotFather: отправь `/mybots` → выбери бота → API Token
2. Скопируй токен заново
3. Перезапусти бота
